# OmniUil AI — VS Code Extension

Scanner de seguranca criptografica pos-quantica para Visual Studio Code.

## Requisitos
- VS Code 1.85+
- Binario OmniUil AI em ~/QSEC/qsec-rust/target/release/qsec

## Uso
1. Ctrl+Shift+P -> "OmniUil AI: Configure Binary Path"
2. Salve qualquer arquivo Python/Java/Go/JS/TS/Rust/C# para scan automatico
3. Ctrl+Shift+P -> "OmniUil AI: Show Last Report"
